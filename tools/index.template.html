TROUBLESHOOTING METHOD

Follow the steps below

1»2»3
  1. 1
    Open Windows PowerShell

    Search Start for PowerShell. Right-click and choose Run as administrator.

  2. 2
    Copy both command lines below

    Paste into PowerShell and press Enter. The menu loads first; your selected troubleshooter loads next.

  3. 3
    Choose your troubleshooting option

    Option 1: console. Option 2: Full GUI. Option 3: Java / website settings. Option 5: CRIS Signer Switcher & Installer. Option 6: APAR Signer Service 7.0.2 (GUI). Review and approve changes.

Open Windows PowerShell as administrator, run the command above, then choose Option 1 (console), 2 (full GUI), 3 (Java / website settings), 5 (CRIS Signer Switcher & Installer), or 6 (APAR Signer Service 7.0.2). Option 3 asks Continue / Cancel for each selected browser; complete the selected site resets in that browser. Option 5 offers Setup BOTH signers automatically with UAC and one setup review. Existing CRIS MSI installations may be removed and their configuration replaced; both packages are validated first. Windows checks run inside the PowerShell tool; this website does not inspect your computer.

Option 2 checks E-Office 4.1.8 on port 55101. Option 6 checks APAR 7.0.2 on port 55103 and downloads its installer only after approval. Both versions are preserved side by side. The selected isLive response must show success and the matching version. Opening the link alone does not verify it. Only a date-expiry warning for the approved signer endpoint may be accepted; other certificate errors need review.

Keep the session-log folder displayed by the tool. MSI details are in dss-install.log. If organization policy blocks the script, ask IT to approve it; policy is not bypassed.
